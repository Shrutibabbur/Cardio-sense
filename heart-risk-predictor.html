// methodology

Grounded in clinical data science

The scoring model is built on features from the UCI Heart Disease dataset — one of the most studied cardiovascular datasets in machine learning research.

Weighted feature scoring
Each clinical variable carries a weight proportional to its documented clinical significance, derived from logistic regression coefficient analysis.
Normalised risk output
Raw scores are normalised and clamped to a 0–100% probability estimate using a sigmoid-inspired function to avoid overconfident extremes.
Three-tier classification
Results are classified as Low (<20%), Moderate (20–45%), or High (>45%) using clinically informed thresholds aligned with Framingham risk categories.

// Weighted clinical risk model
function computeRisk(inputs) {
  let score = 0;

  // Age contribution (max 28pts)
  score += Math.max(0,
    (inputs.age - 30) / 55
  ) * 28;

  // Chest pain type (max 18pts)
  const cpMap = [0, 5, 10, 18];
  score += cpMap[inputs.chestPain];

  // Systolic BP (max 14pts)
  score += Math.max(0,
    (inputs.bp - 100) / 100
  ) * 14;

  // Angina + ECG slope
  score += inputs.angina ? 9 : 0;
  score += [0, 4, 8][inputs.slope];

  // Normalise to 0–100%
  return Math.min(score, 100);
}
